# Dashboard de Cobrança

Sistema web desenvolvido para acompanhamento de metas e desempenho da equipe de cobrança.

## Funcionalidades

- Dashboard com indicadores
- Controle de metas semanais e mensais
- Cadastro de usuários
- Ranking de cobradores
- Gráficos de desempenho
- Tema Dark Mode
- **API REST** completa em .NET
- **Banco de dados** MySQL integrado
- **Autenticação JWT** (em andamento)

## Tecnologias

### Backend
- **.NET 9**
- Entity Framework Core + Pomelo (MySQL)
- JWT Bearer Authentication
- Arquitetura com Controllers e DTOs

### Frontend
- **React 19**
- **Vite**
- TailwindCSS
- Axios para consumo da API
